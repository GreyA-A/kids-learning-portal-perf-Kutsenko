# Веб-портал для навчання дітей «Розумники» (Адаптивність, Кросбраузерність та Метрики)

Лабораторна робота №5 з дисципліни «Розробник фронтенду програмних систем».
Тема: Адаптивність, кросбраузерність та метрики ефективності фронтенду.
Варіант: Загальний (на основі проекту «Розумники»).

## Цілі та завдання роботи:
- Дослідження та оптимізація адаптивності інтерфейсу для брейкпоінтів 360px, 480px, 768px, 1024px, 1440px.
- Забезпечення кросбраузерності (Chrome, Edge, Firefox, Safari, Opera) за допомогою вендорних префіксів та нормалізації.
- Аудит продуктивності за метриками Google Core Web Vitals (LCP, FCP, CLS, TBT, TTI) через інструмент Google Lighthouse.
